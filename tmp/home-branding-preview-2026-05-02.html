5 · Bloque de correcciones · responder antes de aplicar

Las preguntas vienen ordenadas por impacto (1 → 6). La respuesta sugerida (default) está en cursiva.

  1. 1. ¿Confirmás que primary-700 #40792F reemplaza brand.deep #0F2E1F como CTA primario light, en vez de mantener el deep histórico? Default sugerido: SÍ — el doc §4 lo marca como bloqueante por contraste (5.26:1 AA). El hex queda más vivo / menos forest.
  2. 2. ¿Adopto el coral en el bell badge (home-header.tsx) ahora junto con la migración de palette, o lo dejo para una segunda PR de "Fase 3 · accent operativo"? Default sugerido: AHORA — sin esto, el preview side-by-side no muestra el "antes coral / después coral" promised por el doc. Total cost: 1 línea + nuevo token accent.
    • Variante A (sugerida): pintar bell con accent-600/300 ya en este sprint.
    • Variante B: dejar peach legacy hasta Fase 3 separada.
  3. 3. ¿Qué hago con los 5 hex sueltos del diff resumen (§4)? Default sugerido (item por item):
    • #6B3A4F moon plum → mantener literal (es identidad de icono nocturno; no es color de marca).
    • #9EE0B2 dark verde sano → adoptar primary-300 #B2D9A6; deferencia 0.4° de hue, imperceptible.
    • #2E7D5B light verde sano → adoptar primary-700 #40792F; pasa AA sobre primary-100.
    • #0F2A1E texto CTA assistant → adoptar surface-950 #12211A (alias de colors.text dark).
    • Shadow brand.deep@8% → adoptar withAlpha(colors.text, 0.08); conserva el peso visual.
  4. 4. ¿Agrego los tokens nuevos accent, accentSurface, borderAccent a ThemeColors en el mismo PR de Fase 1, o los meto recién en Fase 3? Default sugerido: en Fase 1 — el tipo se extiende y los valores quedan asignados; ningún consumidor los usa todavía. Cero impacto runtime, máxima predictibilidad.
  5. 5. heroGradient light: el doc dice "primary-900 → primary-700 → primary-500". Necesita 4 stops. ¿Uso [primary-900, primary-800, primary-700, primary-500] o [primary-900, primary-700, primary-500, primary-400] para preservar el sentido de "deep → vivo" del actual? Default sugerido: [#27491D, #356327, #40792F, #5EB045]. La última stop más clara que primary-500 puede generar washout en el hero amount cream.
  6. 6. meta-card ACCENT_GRADIENT: ¿la dirección queda primary-300 → accent-300 (verde→coral) tanto en light como en dark? Default sugerido: SÍ. Mantiene la lectura "vas hacia el premio" (verde productivo → coral cálido). El gradient actual (#6FE09A → #F2B58A) tiene la misma narrativa, solo cambian los hex.
