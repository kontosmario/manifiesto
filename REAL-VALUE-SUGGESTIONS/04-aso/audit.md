## 🌎 Análisis de mercado

### Categoría primaria: **Finance**
- Top-grossing en AR/MX/ES: bancos (Mercado Pago, Brubank, Naranja X, Belo)
- Sub-categoría buscada: "personal finance" / "expense tracker"
- Competidores directos en ES: **Splitwise, Wallet by BudgetBakers, Money Lover, Mobills, Monefy, Spendee, YNAB**

### Categoría secundaria: **Lifestyle**
- Permite captar usuarios buscando "organización del hogar" / "vida en pareja"
- Menos competencia que Finance pero traffic relevante

### Categoría
- **Primary:** Finance
- **Secondary:** Lifestyle

### Age Rating
- 4+ (sin contenido adulto)

### Privacy Nutrition Label

Basado en lo que la app recopila:

| Data Type | Linked to User? | Used to Track? | Used For |
|-----------|-----------------|----------------|----------|
| Email | Yes | No | App Functionality, Account Management |
| Name | Yes | No | App Functionality |
| User Content (gastos, finanzas) | Yes | No | App Functionality |
| Identifiers (user_id) | Yes | No | Analytics, App Functionality |
| Usage Data (telemetry) | Yes | No | Analytics, Product Personalization |
| Diagnostics (crashes, performance) | No | No | App Functionality |
| Push Token | Yes | No | App Functionality |

⚠️ "Used to Track" = Yes solo si datos van a third-party advertising. Manifiesto NO trackea publicidad → todo "No".

- Usá ATS (HTTPS) standard de iOS → ITSAppUsesNonExemptEncryption = false (en `Info.plist`)
- App.config.ts → agregar `ios.config.usesNonExemptEncryption: false`

### URLs requeridas

## 📊 Estrategia de ratings

### Apple StoreKit prompt rate limits
- Máximo 3 prompts/año/usuario
- Apple decide cuándo mostrarlos

### Mejor momento para pedir rating

Identificados en la app:
1. Después de cerrar el mes bajo cupo (high satisfaction moment)
2. Después de racha de 30 días
3. Después de uso prolongado (30+ días desde install, 3+ sesiones/semana)

Implementación con `expo-store-review`:
```ts
import * as StoreReview from 'expo-store-review'

async function maybePromptRating() {
  if (await StoreReview.hasAction()) {
    StoreReview.requestReview()
  }
}
```

### Responder reviews
- Setup App Store Connect → Apps → Ratings & Reviews → "Reply" enabled
- Tono: cercano, breve, soluciones concretas
- Target: 100% reviews 3★ o menos respondidas dentro de 48h
